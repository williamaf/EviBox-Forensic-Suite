# 🛡️ EviBox (v4.0.0.5 PRO)

**EviBox** es una aplicación web local desarrollada con Python y FastAPI para organizar, archivar y verificar la integridad de enlaces y recursos web de forma rápida y estructurada.

---

## 🚀 Características

* **Bóveda Organizada:** Los registros y archivos guardados se almacenan separados de la aplicación principal para mayor orden.
* **Integridad (SHA-256):** Generación automática de huella digital para comprobar que los archivos archivados no se modifiquen.
* **Diagnóstico local:** Compatible con comandos de auto-diagnóstico por consola:
  ```cmd
  EviBox.exe --self-test
